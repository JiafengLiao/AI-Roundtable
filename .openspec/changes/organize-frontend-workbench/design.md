# Design

## Layout
首屏工作台使用两栏工作区：主栏展示筛选和热点队列，右栏展示当前上下文检查器。其他管理型页面继续使用单栏，避免 RSS、手动补充、历史和设置页面被右栏挤压。

## Components
- `PageHeader`: 统一页面标题、说明和顶部动作。
- `StatusStrip`: 统一展示后端、RSS、候选热点和草稿状态。
- `HotspotQueue`: 将候选热点列表从工作台容器中拆出，保留现有选择与打开来源逻辑。
- `InspectorPanel`: 根据当前选中热点、圆桌议程、草稿和生成任务展示来源、事实风险、审核清单与下一步状态。

这些组件只接收现有状态和回调，不创建新的跨页面状态，也不引入路由或状态库。

## Visual Direction
界面保持深色专业工具风格，使用冷灰边框、近黑背景和青绿色强调色。候选热点以紧凑队列呈现，减少大卡片占用；状态块和按钮保持稳定尺寸，避免 hover 或异步状态造成布局跳动。

## Compatibility
不修改后端命令、保存格式、导出格式、LLM 调用流程、RSS 抓取流程、TTS/ASR 配置流程。窄屏时检查器下移到主栏之后，导航改为可换行网格。

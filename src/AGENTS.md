# Frontend Instructions

## Scope
This directory owns the React + TypeScript workbench UI.

## Rules
- Build the actual workbench as the first screen.
- Use dense, professional UI for repeated editorial work.
- Keep visual treatment premium and restrained: near-black surfaces, cool gray hierarchy, cyan/teal accents, no ornamental gradients.
- Make every async state visible: idle, running, failed, empty, succeeded.
- Prefer typed data and explicit UI states over stringly ad hoc behavior.
- Keep responsive layouts stable; text must not overflow controls or panels.
